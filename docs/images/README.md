# Product gallery

The PNGs in this directory are rendered captures of the Sudo application UI. They use original geometric **Blue Hour** demo artwork, fictional **Sudo Sessions / Evening Studies** metadata, an example reminder program, and original sample lyric lines. No Spotify account, private email, browser page or user library data is included.

`hero.png` arranges the genuine Home and Wide player captures in a documentation composition. It illustrates the product; the tilted arrangement is not a new application layout.

The screenshots were captured from the production Svelte build with native interfaces simulated for repeatable documentation. They do not establish live account authentication or provider availability. Native Spotify discovery and the optimized executable are verified separately.
