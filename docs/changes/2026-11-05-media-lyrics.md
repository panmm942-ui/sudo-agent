# Video fallback, lyric timing and vocal controls

The player keeps its existing glass, typography, layouts and motion. These changes help Spotify listeners recover unavailable video sources, follow supplied word timings, and adjust the optional local vocal processor without leaving lyrics. Controls use the existing tokens, native keyboard-operable sliders and an explicit unavailable state.

- The selected source is always tried first. With **Try the other video source if unavailable**, Canvas falls back to animated artwork and animated artwork falls back to Canvas. Each source is attempted once per lookup generation, including decoder failures. Both failing leaves the cover and song color. The saved `videoCanvasFallback` preference is retained for compatibility.
- Paused Spotify renderers can throttle the connector heartbeat. Canvas can reuse a validated media snapshot for up to two minutes only when Windows still reports the same title, artist credits, album and duration. The live playback clock retains its shorter freshness checks. Connector source changes now flag Repair, including an app upgrade with an older installed connector.
- **Settings → Spotify → Appearance & reading options → Word-by-word lyrics** highlights supplied Spotify syllable timing or enhanced LRC word timing. Exact text, ordering and finite time bounds are validated across the connector, native receiver and reader. Line-only data stays line-synced. Romanized and translated text do not inherit word offsets from different text. No evenly spaced artificial word timings are generated.
- Vocal reduction setup is always visible in Spotify settings. Installing VB-CABLE is one setup step: the optional runtime, detected cable, physical output and explicit enable switch are also required. No processor starts automatically. A microphone button in inline and fullscreen lyrics opens the vertical vocal slider; it controls the actual processor only while running. Lyrics compensate for its reported audio delay. Escape closes the slider before closing lyrics.

Research: [Spicy Lyrics](https://github.com/Spikerko/spicy-lyrics) documents the distinction between community word timing and line-only sources; [Lyric Miniplayer](https://github.com/rtZenith/Spictify-Lyric-Miniplayer/blob/main/lyrics-overlay.js) demonstrates Spotify's syllable start times and character counts. The implementation here is independent and adds no third-party lyric service or extension dependency.
