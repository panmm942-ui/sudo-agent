Set up iPhone Clock ↗
Send from your iPhone Share Sheet
  1. In Apple Shortcuts, create Send to Sudo. Enable Show in Share Sheet and accept text and URLs.
  2. Add a Text action and insert the Shortcut Input variable into it. This is the text or URL received from the Share Sheet.
  3. Add Get Contents of URL using the action URL below. Choose POST, header Authorization = Bearer [PhoneKey], and a JSON request body: type = Text send, text = the Text action’s output.
  4. Run it manually and check the inbox in Sudo’s PC settings. Only show a success notification after the request succeeds.
Report iPhone battery with a Shortcut

This is an optional report each time you run the Shortcut. It is not a continuous live battery connection.

  1. Create a Shortcut. Add Get Battery State (or Get Device Details → Battery Level, depending on your iOS version) and save the numeric battery percentage.
  2. Get Is Charging using the available Battery State action. Keep it as a Boolean, not the text “true” or “false”.
  3. Add Get Contents of URL for the action URL below, method POST, header Authorization = Bearer [PhoneKey]. JSON body: type = Text battery, percent = Number with the level, charging = Boolean with the charging state.
  4. Test manually. Optionally add a Shortcuts battery or charger automation that runs this Shortcut. iOS permissions or actions may require interaction.
