# Recorded alarm sounds

Unmodified MP3 recordings by Joseph SARDIN, from BigSoundBank. CC0 public domain dedication. These are recordings of real alarm devices, bundled for offline playback. No Apple or other proprietary ringtone used.

- Digital watch: https://bigsoundbank.com/digital-watch-alarm-s2256.html
- Mechanical twin bell: https://bigsoundbank.com/mechanical-alarm-clock-ring-1-s2657.html
- License: https://creativecommons.org/publicdomain/zero/1.0/

Original URLs, byte counts and SHA-256 hashes are in sources.json. Existing Chime/Pulse saved choices map to the digital-watch recording. An oscillator remains only as an emergency decoder/playback failure fallback.
